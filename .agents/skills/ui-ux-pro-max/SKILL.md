This skill provides comprehensive UI/UX design intelligence and search guidelines for building professional user interfaces across multiple platforms.

6. **Chart & Data Visualization**: Recommended chart types (Bar, Line, Donut, Heatmap) and library selections (Recharts, Chart.js, D3).

## Design Execution Principles

- **Aesthetics & Premium Polish**: Avoid plain browser default colors or plain red/blue/green. Use tailored HSL/Hex color palettes with subtle gradients and crisp contrast.
- **Typography Hierarchy**: Use modern sans-serif or serif web fonts with clear font-size and font-weight scaling.
- **Micro-Animations**: Add soft hover effects, smooth transitions, and subtle reveal animations.
- **Responsive Layout**: First-class mobile and desktop responsiveness.
- **Accessibility (a11y)**: Maintain WCAG compliant contrast ratios and interactive element focus states.
